# Writing and checking guides (placeholder)

PLACEHOLDER: a template for future guides. Replace it with real content that
has been checked against a trustworthy source.

Suggested layout for each guide:

1. What this covers, in one line.
2. What you need (tools, parts).
3. Steps.
4. Where the information came from (book, manual, organisation) and when it
   was checked.

Keep each guide short and focused on one task so keyword search finds it.
